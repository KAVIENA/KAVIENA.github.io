# Kaviena Sharon Portfolio

A static, multi-page portfolio ready for GitHub Pages. No build step is required.

## Preview locally

Open `index.html` in a browser, or run `python -m http.server 8000` and visit `http://localhost:8000`.

## Deploy on GitHub Pages

1. Create a new GitHub repository (for example, `portfolio`).
2. Upload these files or push this folder to the repository's `main` branch.
3. On GitHub, open **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**, then select `main` and `/ (root)`.
5. Save. GitHub will publish the site at `https://YOUR-USERNAME.github.io/portfolio/`.

The `.nojekyll` file makes sure GitHub serves the static files exactly as written.

## Contact form

The contact form opens the visitor's email client addressed to `kaviena.global@gmail.com`. A backend form service is needed if you want messages delivered without opening an email application.
